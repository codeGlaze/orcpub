# Spellcasting -- Issue Deep Dive

> 20 issues (13 bugs, 7 enhancements) | [Back to Index](INDEX.md)

## Summary

The spellcasting system is one of the most bug-dense areas of OrcPub, with issues spanning multiclass spell slot calculation, prepared spell tracking, spell list composition, and PDF rendering. The root causes concentrate in a handful of key files: `template_base.cljc` (multiclass level aggregation uses `int` which always rounds down, breaking Artificer), `options.cljc` (spell slot schedules for 6 different progression factors), `character.cljc` (prepared spell state management), and `pdf_spec.cljc` (spell card/sheet output). Many bugs are interconnected -- the multiclass cluster (#437, #435, #47) all trace to how `?total-spellcaster-levels` and `?spell-slot-factors` interact in `template_base.cljc` lines 263-299.

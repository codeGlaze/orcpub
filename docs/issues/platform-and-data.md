# Platform & Data Exchange — Issue Deep Dive

> 16 issues (1 bug, 15 enhancements) | [Back to Index](INDEX.md)

## Summary

This domain covers account/platform infrastructure (authentication, storage, deployment, sharing) and data interchange (import/export of characters and homebrew content). There is only one bug -- the Datomic Free availability issue (#549) -- which is already being addressed by the ongoing stack modernization (#652). The 15 enhancements range from quick UX wins (Enter-key login, notification rate-limiting) to large architectural features (cloud storage linking, VTT export, file format compatibility). Several import/export requests are partially served by the recently implemented content reconciliation system, which detects missing orcbrew dependencies.

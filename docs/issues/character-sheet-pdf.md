# Character Sheet & PDF -- Issue Deep Dive

> 18 issues (4 bugs, 14 enhancements) | [Back to Index](INDEX.md)

## Summary

This domain covers PDF character sheet generation (server-side Clojure via PDFBox), the fillable PDF templates in `resources/`, the `pdf_spec.cljc` field-mapping layer, and the client-side character sheet display in `views.cljs`. The PDF pipeline works by: (1) `pdf_spec.cljc` extracts character data into a flat field map, (2) `pdf.clj` fills a pre-built fillable PDF template using PDFBox's AcroForm API, and (3) `routes.clj` selects the correct template (4 styles x 7 spell-page variants = 28 templates) and streams the result. Most bugs relate to data not reaching PDF fields or text overflow in fixed-size boxes. Most enhancements request new PDF layouts, additional fields, or alternative sheet formats.

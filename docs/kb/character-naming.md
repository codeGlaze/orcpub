# Character Naming System

## Problem

Characters save with blank names, making them hard to identify in party lists,
character selectors, and encounter dropdowns.

## Solution (implemented 2026-02-22)

Three-layer approach, all in events.cljs and views.cljs:

### 1. Auto-save: Descriptive label

`make-summary` generates a descriptive label when `character-name` is blank:

```clojure
(descriptive-character-label race subrace classes levels)
;; => "High Elf Ranger 3"
;; => "Human Fighter 5/Wizard 3"
;; => "Adventurer" (nothing selected yet)
```

The label goes into the **summary only** (what lists/parties display).
The entity's name field stays blank - the user still sees an empty input.

### 2. Manual save: Random name

`:save-character` generates a random name when `character-name` is blank:

```clojure
(generate-random-name built-character)
;; => "Adran Amakiir" (for an elf)
;; => "Brottor Balderk" (for a dwarf)
;; => random human name (for unsupported/custom races)
```

The generated name is:
- Set on the entity in db (persists across future edits)
- Overridden in the summary (make-summary produced a descriptive label)
- POSTed to the server

### 3. Display fallback: Views helper

`character-display-name` in views.cljs returns the character's name or a
descriptive fallback from the summary's race/class fields:

```clojure
(character-display-name summary)
;; Returns character-name if non-blank, else descriptive label
```

Used in three spots:
- `character-summary-2` (main list component)
- `character-selector` (encounter dropdown)
- Party add dropdown

## Tracking "was the name set by the user?"

No flag needed. Blank entity name = not set by user. Non-blank = set by user
(or previously generated by manual save).

## Name Generator System

Located in `src/cljc/orcpub/dnd/e5/character/random.cljc`.

### Supported races

| Race | Subraces | Gendered |
|------|----------|----------|
| Human | 8 subtypes (Calishite, Chondathan, Turami, Shou, Damaran, Illuskan, Rashemi, Mulan) | Yes |
| Elf | None (generic elf) | Yes |
| Dwarf | None (generic dwarf) | Yes |
| Halfling | None (generic halfling) | Yes |

### Dispatch mechanism

```clojure
(defmulti random-name (fn [{:keys [race subrace sex]}] [race subrace sex]))
```

### Fallback for unsupported races

The `:default` method picks a random human subrace and sex:
```clojure
(defmethod random-name :default [_]
  (random-name {:race ::human :subrace (random-human-subrace) :sex (random-sex)}))
```

`random-name-result` also normalizes inputs - nil race/sex/subrace are replaced
with random values. Custom/homebrew races (Tiefling, Aasimar, Tabaxi, etc.)
all fall back to human names.

### Helper function

`generate-random-name` in events.cljs extracts race/subrace/sex from a built
character and calls `random-name-result`:

```clojure
(defn generate-random-name [built-char]
  (let [race-kw (common/name-to-kw (char5e/race built-char) "orcpub.dnd.e5.character.random")
        ...]
    (:name (char-rand5e/random-name-result {:race race-kw ...}))))
```

This is also used by `::char5e/set-random-name` (the dice button in the
character builder's description fields).

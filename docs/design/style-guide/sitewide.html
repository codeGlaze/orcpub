Bold across the site

The feature/style-guide build, running. Before is what integration ships (Open Sans 400 only, buttons in Arial). After is the branch: 400/600/700 loaded, tabs 700, page titles 600, buttons in Open Sans. Loading the bold weights doesn’t only affect the header: everything the code marks bold gets heavier.

Two things to decide before this merges

  • Bold everywhere. Spell and monster names, section headings and the builder’s intro text all get heavier, because the code has always asked for bold there and it never showed. If that’s too much, the generic bold (.f-w-b, :bold) could be set to 600 across the site, with only the header tabs at 700.
  • “My Content” wraps. At 700 the header tab no longer fits one line at 1280px wide. Options: accept the wrap (it already wraps on narrower screens), tighten the tab’s letter spacing, or take the tabs to 600.

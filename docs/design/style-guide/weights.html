Header weights

The header tabs and the page title from the running site, with real Open Sans at several weights. Both are marked bold in the code, but Chrome has always shown them at 400 because bold was never loaded. With the weights loaded, each can be set to whatever looks right.

Together, in context

Weight reads relative to what’s beside it, so the pair has to be judged as a pair. Title: 600. Tabs: 700 looks fine, not yet confirmed.

How this would be set

  • Both use the generic bold class .f-w-b. The fix gives the tab titles and the page title their own weight in the Garden stylesheet, so loading the real bold doesn’t change how they look unless you choose to.
  • 500 needs that weight loaded too. Open Sans comes as one variable file, so 400, 500, 600 and 700 cost the same as 600 and 700 alone.

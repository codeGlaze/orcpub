The yellow buttons

Shown at twice actual size so the strokes are visible. You were right: they got lighter. They used to be Arial Bold; the first pass made them Open Sans 600. They’re now Open Sans 700. The underlying problem is contrast: white on this amber is 2.1:1, well under the 4.5:1 readable minimum, and thin strokes expose it. Dark text on amber is 7.8:1, and the portrait drawer’s buttons already use it. It’s shown last for comparison and is not built.

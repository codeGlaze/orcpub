Open Sans weights, before and after

The character builder in the running site. Before is the site as it ships: Open Sans loaded at weight 400 only. After adds the 600 and 700 weights from Google Fonts and changes nothing else. Toggle between them and watch the header tabs, the page title and the class name.

What changes

  • Header tabs, page title, class name: the stylesheet asks for bold, but in Chrome and Edge they render at regular weight, because only regular is loaded. After the fix they’re bold as intended. Firefox and Safari may fake the bold instead, which looks smeared.
  • The amber buttons don’t change. They aren’t in Open Sans at all. Buttons get the browser’s own default font (Arial), and nothing in the stylesheet tells them to use the site font. That’s a second one-line fix: button { font-family: inherit }.
  • The fix itself: in index.clj, load Open+Sans:wght@400;600;700 instead of plain Open+Sans. For a modern browser that’s one more font file, about 48 KB for Latin text, shared by both weights.

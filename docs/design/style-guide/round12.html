Button height

With the padding unchanged the buttons grow with the text: 31px at 14px, 32px at 15px, 34px at 16px. If the row shouldn’t get taller, the vertical padding can shrink to match (6px to 4.5px at 16px) so the button stays 31px and only the label grows.

Site mark colour pairs

Each colour an artist can pick has a dark-theme half and a light-theme half, shown as a split swatch. Visitors see the half that matches their theme. Two ways to pair them are shown. Everything is captured from the running site.

Trade-off

  • Paired colours give each theme its best colour, the way the site pairs amber with slate blue. But the artist’s mark changes colour when a visitor switches themes, and gold on light is the site’s own slate blue.
  • Same colour, deeper keeps the mark recognisably the same in both themes, the way Twitch stays purple, but the light theme gets muddier versions.
  • The yellow in both sets is the site’s warning-yellow, which also marks problems in the library health bar.

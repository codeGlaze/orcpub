Unblock the D&D character "Features" tab

This is a temporary client-side workaround so a stuck character can open its Features tab without going to a black screen. (The real fix is deploying the code change.)

Drag this button up to your bookmarks bar →

⚔ Unblock Features tab

Can't drag? Right-click your bookmarks bar → “Add page/bookmark”, and paste the code below as the URL.

How to use it

  1. Make sure the bookmarks bar is visible (Chrome/Edge: Ctrl/Cmd+Shift+B).
  2. Drag the orange button onto the bookmarks bar (or use the right-click fallback above).
  3. Open the character page and let it finish loading (it loads fine on Summary/Combat).
  4. Before clicking Features, click the ⚔ Unblock Features tab bookmark — you’ll see “armed”.
  5. Now click Features. It renders instead of going black.

If the page is already black, reload first, then run the bookmark, then click Features. The workaround lasts until you reload; just click the bookmark again each visit.
